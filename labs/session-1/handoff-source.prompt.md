# درخواست در نشست فعلی Claude Code

می‌خواهم ادامهٔ کار همین پروژه را به Codex بسپارم. بدون تغییر کد محصول، یک فایل HANDOFF.md در ریشهٔ همین پروژه بساز.

فقط براساس گفت‌وگوی در دسترس و فایل‌ها و فرمان‌هایی که واقعاً بررسی کرده‌ای بنویس:

1. هدف و معیار پذیرش کار فعلی.
2. مسیر پروژه، شاخه و commit فعلی، و وجود تغییرهای ثبت‌نشده. اگر Git موجود نیست صریح بگو.
3. کار انجام‌شده، فایل‌های مرتبط و دلیل تصمیم‌های مهم.
4. کار ناتمام، ریسک‌ها و یک اقدام بعدی مشخص.
5. فرمان و نتیجهٔ آخرین آزمون؛ اگر اجرا نشده، «اجرا نشده» بنویس.
6. قواعد پروژه که عامل بعدی باید از فایل‌های مشخص بخواند؛ قواعد اختصاصی CLAUDE.md را خودکار معادل AGENTS.md فرض نکن.

خلاصه را کوتاه و قابل بررسی نگه دار. credential، secret، فایل auth، تاریخچهٔ خصوصی نامرتبط یا دادهٔ محیط خارج از پروژه را وارد فایل نکن. اگر برای یک مورد شاهد نداری، آن را «نامعلوم» ثبت کن. شناسهٔ نشست مبدأ را شناسهٔ قابل resume در Codex معرفی نکن. پس از نوشتن فایل، ویرایش کد را متوقف کن تا دو عامل همزمان کار نکنند.
