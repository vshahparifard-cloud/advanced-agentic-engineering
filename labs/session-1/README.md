# آزمایشگاه 1 — مهندسی نشست و قرارداد

## پیش از کلاس
Node.js 22 یا بالاتر، Python 3.11 یا بالاتر و Git لازم است. تمرین را در یک checkout آموزشی اجرا کنید. هیچ کلید یا فایل ورود را commit نکنید. همهٔ فرمان‌ها از ریشهٔ مخزن هستند مگر مسیر دیگری ذکر شود. فایل‌های کامل و پاسخ مرجع همراه تمرین‌اند؛ فعالیت کلاس بازبینی، تغییر کنترل‌شده و آزمون شکست است.

## هدف و خروجی
یک نشست قابل ادامه با قرارداد روشن، آزمون رفتاری و checkpoint بسازید. خروجی: prompt.md، گزارش آزمون و یادداشت تصمیم. زمان فعالیت: اسلایدهای ۱۳ تا ۱۷، مجموع ۲۵ دقیقه.
## گام‌ها — هر گام ۵ دقیقه
1. وارد labs/session-1 شوید. AGENTS.md و subtotal.mjs را بخوانید. آزمون خط پایه را اجرا کنید.
2. prompt.md را بازبینی کنید. مثال اعشاری و منع تبدیل رشته را حفظ کنید؛ یک مثال خودتان اضافه کنید.
3. آزمون subtotal برای ورودی آرایه‌نبودن بنویسید. پیش از تغییر پیاده‌سازی، نتیجهٔ واقعی را ثبت کنید.
4. از الگوی checkpoint.example.md یک یادداشت برای همکار بسازید. هدف، تصمیم، شاهد و قدم بعدی لازم است.
5. اگر CLI رسمی و حساب مجاز دارید، درخواست خواندنی را اجرا و سپس نشست را ادامه دهید. در غیر این صورت یک هم‌گروهی فقط با checkpoint کار را ادامه دهد.
```sh
cd labs/session-1
npm test
codex --version
codex login status
codex exec --sandbox read-only "Read AGENTS.md and review subtotal; do not edit files"
codex resume --last
```
## نتیجهٔ مورد انتظار و پاسخ مرجع
چهار آزمون موجود باید پاس شوند. تابع برای [1.5,2.25] مقدار 3.75 می‌دهد و NaN، Infinity، رشته و عدد منفی را رد می‌کند. برای افزودن آزمون آرایه‌نبودن می‌توانید assert.throws(() => subtotal(null), TypeError) بنویسید؛ پیاده‌سازی موجود باید آن را پاس کند. تغییر کد بدون نیاز امتیاز اضافه ندارد.
## تشخیص خطا
اگر npm test از ریشه اجرا شد، آزمون‌های کل پروژه را می‌بینید؛ در این تمرین مسیر جاری labs/session-1 است. اگر login معتبر نیست، فرمان مدل را متوقف کنید و مسیر آفلاین را ادامه دهید. read-only اجازهٔ تغییر فایل نمی‌دهد؛ درخواست ویرایش باید در مخزن مورد اعتماد و با اختیار صریح workspace-write انجام شود.
## معیار تحویل
قرارداد ورودی دقیق، حداقل یک آزمون لبهٔ افزوده، خروجی واقعی آزمون و checkpoint قابل استفاده توسط نفر دوم. گزارش باید بگوید اجرای زندهٔ مدل انجام شده یا فقط مسیر آفلاین تأیید شده است.
