# نمونهٔ آموزشی یادداشت تحویل

این فایل نمونهٔ توضیحی است، گزارش وضعیت پروژهٔ واقعی دورهٔ قبلی شما نیست. در دموی واقعی، عامل مبدأ باید براساس همان پروژه HANDOFF.md تازه بنویسد.

- هدف: افزودن آزمون برای رد ورودی null در تابع subtotal.
- معیار پذیرش: ورودی غیرآرایه با TypeError رد شود و آزمون‌های قبلی موفق بمانند.
- پروژه و Git: مسیر، شاخه، commit و تغییرهای ثبت‌نشده را در پروژهٔ واقعی بررسی و ثبت کنید؛ در این نمونه مقدار واقعی ادعا نشده است.
- تصمیم: قرارداد تابع تغییر نکند؛ فقط شاهد رفتاری اضافه شود.
- فایل‌های مرتبط: subtotal.mjs، subtotal.test.mjs و AGENTS.md در پوشهٔ آزمایشگاه جلسهٔ اول.
- انجام‌شده: در این نمونهٔ فرضی کد و آزمون‌های قبلی مطالعه شده‌اند.
- آزمون: نتیجهٔ تازه‌ای در این فایل نمونه ادعا نشده است؛ در تحویل واقعی فرمان و نتیجهٔ واقعی لازم است.
- باقی‌مانده: آزمون null نوشته و اجرا شود؛ اگر همان حالا موجود است، دوباره اضافه نشود.
- اقدام بعدی: عامل گیرنده ابتدا فایل آزمون و وضعیت Git را بررسی کند، سپس قدم بعدی را توضیح دهد.

لاگ خام، فایل ورود و کلید API داخل این یادداشت قرار نمی‌گیرد. یادداشت می‌تواند اشتباه یا قدیمی باشد و باید با فایل‌های واقعی تطبیق داده شود.
