# معماری و مرزهای اعتماد
این پروژه یک سایت ایستا به‌همراه آزمایشگاه‌های مستقل است. مرورگر فقط محتوای عمومی را نمایش می‌دهد؛ secret، model API و پایگاه داده داخل سایت نیستند. اسکریپت‌های زنده در محیط محلی فراگیر اجرا می‌شوند.

## نمای استقرار
محتوای JSON و Markdown ← اعتبارسنجی و آزمون ← ساخت dist ← artifact GitHub Actions ← GitHub Pages ← مرورگر فارسی RTL.

## معماری شش جلسه
نمودارهای هر جلسه در اسلاید یازدهم به‌صورت HTML قابل دسترس و قابل چاپ نمایش داده می‌شوند. نمودار ترکیبی پروژه نیز در صفحهٔ اصلی وجود دارد.

## مرزهای امنیتی
1. قرارداد و تنظیم میزبان، اختیار عامل را تعیین می‌کنند؛ دادهٔ ابزار نمی‌تواند آن را گسترش دهد.
2. MCP فقط فایل مشخص content/course.json را می‌خواند؛ shell، URL دلخواه یا انتشار ندارد.
3. Gateway واقعی کلیدها را در environment سمت سرویس نگه می‌دارد؛ browser هیچ کلیدی دریافت نمی‌کند.
4. حافظهٔ قطعی query را با tenant محدود می‌کند. مدل Graphiti و زیرساخت آن جداگانه باید سیاست دسترسی داشته باشند.
5. runner اجرای shell string ندارد و state را اتمیک می‌نویسد؛ این کنترل جای sandbox سیستم‌عامل را نمی‌گیرد.
6. PR و MR فقط normalize می‌شوند؛ نوشتن، پیام و merge در مثال آموزشی فعال نیست.

## قرارداد دادهٔ سایت
content/course.json آرایهٔ شش جلسه است. هر جلسه id، title، en، description، tags، duration و slides دارد. هر اسلاید title، points، notes و duration دارد؛ جمع زمان هر جلسه ۱۲۰ دقیقه است. جلسهٔ اول ۲۵ و بقیهٔ جلسه‌ها ۲۴ اسلاید دارند. فیلدهای اختیاری diagram، code و quiz براساس محتوای اسلاید تنظیم می‌شوند. تمام متن در رابط escape می‌شود و هیچ HTML از JSON اجرا نمی‌شود.

## پایداری و کارکرد مرورگر
ذخیرهٔ پیشرفت و شمارهٔ اسلاید در localStorage است و به دستگاه محدود می‌شود. خاموش بودن storage نباید مانع مطالعه شود. فایل‌های سیلابس و یادداشت‌های HTML بدون JavaScript خوانده می‌شوند. شبکهٔ خارجی یا CDN برای نمایش فونت و سایت لازم نیست؛ دانلود اولیهٔ سایت اینترنت می‌خواهد.

## حدود تولیدی
برای سرویس عمومی MCP باید OAuth و rate limit واقعی اضافه شود. برای چند runner به ledger و قفل مشترک نیاز است. برای مدل‌ها، تست‌های زندهٔ کیفیت و هزینه و سیاست retention لازم است. مثال‌های آموزشی ادعای زیرساخت تولیدی کامل ندارند.
