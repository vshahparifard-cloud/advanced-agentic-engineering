# گزارش تأیید نسخه
## بررسی محلی
- ساختار دوره: شش جلسهٔ ۱۲۰ دقیقه‌ای و ۱۴۴ اسلاید با یادداشت اختصاصی، نمودار، کد و سنجش.
- ۱۴ آزمون Node برای قرارداد محتوا، تابع جمع، گزارش شواهد و سیاست fallback موفق شدند.
- ۲ آزمون قرارداد HTTP مدل، ۳ آزمون حافظه و ۷ آزمون runner و PR/MR موفق شدند. مجموع آزمون‌های قطعی: ۲۶.
- client و server واقعی MCP با SDK نسخهٔ 1.30.0 اجرا شدند: initialize، کشف دو ابزار، جستجوی محدود، نتیجهٔ خالی، رد limit نامعتبر و خواندن resource با جمع زمان ۷۲۰.
- build شش مسیر ارائه، ۱۸ سند HTML و بستهٔ ZIP تولید کرد. ۲۵۸ پیوند محلی بررسی شدند.

## مرز تأیید
سرویس‌های واقعی OpenRouter، LiteLLM، Langfuse و Graphiti و اجرای CLI مدل با حساب فراگیر، نیاز به اعتبار و زیرساخت مستقل دارند. آزمون‌های قطعی این پروژه جای آن اتصال‌ها را نمی‌گیرند. فرمان‌ها و قراردادها از منابع رسمی در sources.md بازبینی شده‌اند.

## بررسی مرورگر
تمام ۱۴۴ اسلاید از طریق کنترل انتخاب اسلاید در مرورگر بارگذاری شدند؛ هر شش ارائه ۲۴ عنوان مجزا نشان دادند. جستجوی Graphiti یک جلسه برگرداند؛ بازخورد پاسخ درست و غلط، باز کردن یادداشت مدرس، فهرست و کلید Home بررسی شدند. پیوند مستقیم اسلاید پس از جابه‌جایی، مسیر ارائه را حفظ می‌کند. بررسی بصری دسکتاپ انجام شد. تنظیم viewport ابزار مرورگر اندازهٔ واقعی صفحه را تغییر نداد؛ بنابراین آزمون بصری موبایل تأیید نشده است، هرچند سبک‌های responsive در کد وجود دارند.

## نسخه‌های SDK و قرارداد زنده
MCP 1.30.0، Graphiti 0.31.2، Langfuse 3.15.0 و LiteLLM 1.102.4 نصب شدند. امضاهای Graphiti.add_episode و Graphiti.search و Langfuse generation.update با کد نمونه تطبیق داده شدند. config درگاه parse شد. این بررسی، اجرای زندهٔ سرویس‌ها یا کیفیت پاسخ مدل را تأیید نمی‌کند.

## آزمون بستهٔ دانلود
بستهٔ ZIP در پوشهٔ موقت مستقل استخراج شد و npm run check شامل همهٔ آزمون‌ها و ساخت مجدد با موفقیت اجرا شد. بسته شامل کد، منابع ساخت، فونت، یادداشت‌ها و آزمایشگاه‌هاست.
