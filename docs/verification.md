# گزارش تأیید نسخه
## بررسی محلی
- ساختار دوره: شش جلسهٔ ۱۲۰ دقیقه‌ای و ۱۴۷ اسلاید با یادداشت اختصاصی، نمودار، کد و سنجش.
- ۱۵ آزمون Node برای قرارداد محتوا، تابع جمع، گزارش شواهد و سیاست fallback موفق شدند.
- ۲ آزمون قرارداد HTTP مدل، ۳ آزمون حافظه و ۷ آزمون runner و PR/MR موفق شدند. مجموع آزمون‌های قطعی: ۲۷.
- client و server واقعی MCP با SDK نسخهٔ 1.30.0 اجرا شدند: initialize، کشف دو ابزار، جستجوی محدود، نتیجهٔ خالی، رد limit نامعتبر و خواندن resource با جمع زمان ۷۲۰.
- build شش مسیر ارائه، ۱۸ سند HTML و بستهٔ ZIP تولید کرد. ۲۵۹ پیوند محلی بررسی شدند.

## مرز تأیید
سرویس‌های واقعی OpenRouter، LiteLLM، Langfuse و Graphiti و اجرای CLI مدل با حساب فراگیر، نیاز به اعتبار و زیرساخت مستقل دارند. آزمون‌های قطعی این پروژه جای آن اتصال‌ها را نمی‌گیرند. فرمان‌ها و قراردادها از منابع رسمی در sources.md بازبینی شده‌اند.

## بررسی مرورگر
تمام ۱۴۷ اسلاید از طریق کنترل انتخاب اسلاید در مرورگر بارگذاری شدند؛ جلسهٔ اول ۲۷ و هر جلسهٔ دیگر ۲۴ عنوان مجزا نشان دادند. جستجوی Graphiti یک جلسه برگرداند؛ بازخورد پاسخ درست و غلط، باز کردن یادداشت مدرس، فهرست و کلید Home بررسی شدند. پیوند مستقیم اسلاید پس از جابه‌جایی، مسیر ارائه را حفظ می‌کند. بررسی بصری دسکتاپ انجام شد. تنظیم viewport ابزار مرورگر اندازهٔ واقعی صفحه را تغییر نداد؛ بنابراین آزمون بصری موبایل تأیید نشده است، هرچند سبک‌های responsive در کد وجود دارند.

## نسخه‌های SDK و قرارداد زنده
MCP 1.30.0، Graphiti 0.31.2، Langfuse 3.15.0 و LiteLLM 1.102.4 نصب شدند. امضاهای Graphiti.add_episode و Graphiti.search و Langfuse generation.update با کد نمونه تطبیق داده شدند. config درگاه parse شد. این بررسی، اجرای زندهٔ سرویس‌ها یا کیفیت پاسخ مدل را تأیید نمی‌کند.

## آزمون بستهٔ دانلود
بستهٔ ZIP در پوشهٔ موقت مستقل استخراج شد و npm run check شامل همهٔ آزمون‌ها و ساخت مجدد با موفقیت اجرا شد. بسته شامل کد، منابع ساخت، فونت، یادداشت‌ها و آزمایشگاه‌هاست.

## CI و انتشار — تأییدشده
در ۶ نوامبر ۲۰۲۶، پس از ورود مجاز GitHub CLI، منبع GitHub Pages از انتشار مستقیم شاخه به GitHub Actions تغییر داده شد. اجرای [42228420938](https://github.com/vshahparifard-cloud/advanced-agentic-engineering/actions/runs/42228420938) روی commit 998c9abb111550105f6040c4174e3496bfdfa886 با موفقیت کامل build و deploy پایان یافت. آزمون‌های قطعی، اتصال واقعی MCP و بررسی پیوندها در همین اجرا موفق بودند.

[سایت منتشرشده](https://vshahparifard-cloud.github.io/advanced-agentic-engineering/) مستقیماً بررسی شد. صفحهٔ اصلی، فایل دادهٔ دوره، فونت، بستهٔ ZIP، سیلابس، هر شش ارائه و هر شش راهنمای آزمایشگاه، مجموعاً ۱۷ مسیر، پاسخ HTTP 200 دادند. هر شش ارائه روی دامنهٔ اصلی در مرورگر باز شدند و ۲۴ گزینهٔ اسلاید و محتوای اسلاید پایانی آن‌ها تأیید شد. نمودار جلسهٔ اول نیز در نسخهٔ آنلاین نمایش داده شد.

## سابقهٔ رفع مانع انتشار
اجراهای اولیه آزمون‌ها را گذراندند ولی در Configure Pages متوقف شدند. پس از تنظیم Pages روی workflow و انتشار موفق، پاسخ‌های قدیمی 404 برای مدت کوتاهی دیده شدند؛ بررسی مجدد تمام ۱۷ مسیر موفق بود. این مانع برطرف شده است. محدودیت‌های سرویس‌های زنده و آزمون بصری موبایل، مطابق بخش‌های بالا همچنان جدا از انتشار سایت هستند.

## تکمیل تحویل بین عامل‌ها — ۷ نوامبر ۲۰۲۶
یک اسلاید تحویل Claude Code محلی به Codex و دو درخواست آمادهٔ مبدأ و مقصد و نمونهٔ یادداشت به جلسهٔ اول افزوده شد. جلسهٔ اول ۲۷ اسلاید و همچنان ۱۲۰ دقیقه دارد. زمان نمایشگر و چاپ و دفترچهٔ مدرس از مدت واقعی اسلایدها محاسبه می‌شود؛ آزمون مرز زمانی، بازهٔ ۴۸–۵۲ دقیقهٔ تحویل، شروع آزمایشگاه در دقیقهٔ ۶۰ و پایان جلسه در دقیقهٔ ۱۲۰ را تأیید کرد. هر ۱۴۷ اسلاید در مرورگر محلی بارگذاری شدند. نمونهٔ config.toml با parser استاندارد TOML بررسی می‌شود. انتقال واقعی یک نشست خصوصی کاربر اجرا نشده است؛ گردش‌کار پیشنهادی، تحویل زمینه و کد قابل بررسی است و تبدیل تاریخچهٔ داخلی محصول‌ها را ادعا نمی‌کند.

## Fork و ابزارهای نشست — تکمیل ۷ نوامبر ۲۰۲۶
دو اسلاید مقایسهٔ Fork و انتخاب Resume، New/Clear، Compact، Worktree، Sidechat و Rewind به جلسهٔ اول افزوده شد. شمار جلسهٔ اول ۲۷ و کل دوره ۱۴۷ اسلاید است؛ جمع زمان جلسه ۱۲۰ دقیقه و کل دوره ۷۲۰ دقیقه باقی ماند. مرز شروع آزمایشگاه همچنان دقیقهٔ ۶۰ است. تفاوت /branch و /fork در Claude Code و حفظ workspace در Antigravity CLI از منابع رسمی بررسی شدند. قابلیت رسمی /import در Codex نیز در بررسی جدید تأیید و توضیح قبلی HANDOFF تکمیل شد. فرمان‌های حساب‌محور یا مهاجرت نشست‌های خصوصی اجرا نشده‌اند؛ صحت محتوا با سند و صحت نمایش و زمان‌بندی با آزمون و مرورگر بررسی می‌شود.
