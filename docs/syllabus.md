# سیلابس مهندسی پیشرفتهٔ ایجنت‌های هوش مصنوعی

۶ جلسه × ۱۲۰ دقیقه = ۷۲۰ دقیقه = ۱۲ ساعت. زبان آموزش فارسی و سطح دوره متوسط رو به پیشرفته است. زمان آزمایشگاه، سنجش و بحث در همین ۱۲۰ دقیقه محاسبه شده است. نصب و دریافت کلیدها پیش‌نیاز پیش از کلاس است.

## پیش‌نیازها
آشنایی با Git، خط فرمان، Python یا JavaScript و مفاهیم پایهٔ مدل زبانی. Node.js 22+، Python 3.11+، اینترنت برای نصب وابستگی‌ها و یک ویرایشگر لازم است. Docker، حساب مدل و سرویس‌های زنده برای مسیر اختیاری اتصال واقعی‌اند؛ تمرین‌های قطعی بدون هزینهٔ API قابل اجرا هستند.
